# Convert Beaconcha.in rewards.json to csv

Tool to convert rewards data from beaconcha.in website to csv for option to use them in excel for tax calculation

## How to use
2) Create a new directory for this project
1) Into the directory, download rewards.json file for each validator id you need to include. Rewards json file for each validator may be opened right in the browser through a link
`https://beaconcha.in/dashboard/data/allbalances?validators=<validatorId>` (e.g `https://beaconcha.in/dashboard/data/allbalances?validators=1111`)
Add a name of validator indice (index) to each downloaded file
3) Download a calculation script from this git repository
